#  Lean4 Novikov descent

This is a formalization of the paper [Descending finite projective modules from
a Novikov ring](https://arxiv.org/abs/2402.17852).

- Blueprint website: <https://dongryul-kim.github.io/lean4-novikov/blueprint/>
- Blueprint PDF: <https://dongryul-kim.github.io/lean4-novikov/blueprint.pdf>

Most of the work was done by various AI models, under some human guidance and
review.
